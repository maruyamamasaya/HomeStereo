# UI候補A: アーティスト／お気に入り／履歴

## 実施内容

- アーティスト一覧をArtwork中心の可変グリッドへ変更した。
- アーティスト詳細を概要、全曲再生／シャッフル、アルバム単位の曲一覧で構成した。
- お気に入りと再生履歴をArtwork付きの共通曲行へ変更した。
- 再生中、ファイルなし、Library未解決をiconと文言で区別した。
- お気に入り／履歴の空状態に「曲を見る」を追加し、取得失敗を非モーダル表示にした。
- Library周辺のFavorite／Playlist／Queue／missing表記を利用者向け日本語へ寄せた。
